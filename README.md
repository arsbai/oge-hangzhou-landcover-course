# OGE 杭州七类土地利用分类课堂代码

本项目用于开放地球引擎（OGE）课堂演示。代码在 OGE 开发中心在线运行，完成 2025 年杭州市 Sentinel-2 影像检索、多景合成、指数计算、随机森林训练、七类土地利用/覆盖分类和地图显示。

## 分类体系

| 编码 | 类别 |
|---:|---|
| 1 | 水体 |
| 2 | 林地 |
| 3 | 湿地/淹水植被 |
| 4 | 耕地 |
| 5 | 建成区 |
| 6 | 裸地 |
| 7 | 灌木草地 |

## 运行前准备

1. 登录 [OGE 平台](https://www.openge.org.cn/)。
2. 在“个人中心 → 我的数据 → 上传数据”中上传：
   - `HZ_boundary.geojson`
   - `HZ2025_reference_train_20m.tif`
3. 打开“开发中心”，新建 Python 脚本。
4. 将 `hangzhou_landcover_oge_classroom.py` 的代码复制到编辑器并运行。

课堂版默认使用 30 棵树并显示地图，不提交导出。正式计算可将 `NUM_TREES` 改为 `100`，将 `EXPORT_RESULT` 改为 `True`。

## 数据与精度说明

训练标签来自公开土地覆盖参考产品的空间抽样，用于课程演示，不属于独立实地调查真值。启用 `EVALUATE_RESULT` 前，还需上传 `HZ2025_reference_validation_20m.tif`。由该验证标签计算的指标应表述为“参考一致性”，不宜称为独立实测精度。

## 运行环境

本代码使用 OGE 平台的 `oge` 接口和云端算子，不能直接作为普通本地 Python 脚本运行。
